# Homework Instructions

This document is intended to provide instructions on how homework can be turned in this semester. If you have questions, please ask. 

## Canvas

All homework will be assigned and turned in on our class Canvas Page. There are three options you can use to turn in your homework, listed in order of preference. 


## Private Github Repository (First Choice)

This is the strongly preferred option. 

Here, you will build out a github repository for this course. To make it easier for us to grade your work, please complete these steps: 
* Create a **private** github repository with the following name: ds6021-f26-[computeid], all lower case. Mine is [ds6021-f26-pjs8ph](https://github.com/mfriedel/ds6021-f26-pjs8ph). (Note that my repository is public in order to serve as an example!)
* Add myself ([mfriedel](https://github.com/mfriedel)) and Yuyang ([EstherrCheng](https://github.com/EstherrCheng)) as collaborators on the repo. This means that Yuyang and I will be able to see your submissions, but no one else will. 

Work for each assignment will be committed to this repository, and **turned in on Canvas as a link to the appropriate file or files in this repository**. You have flexibility in how you turn things in, but please make it easy for Yuyang to find and grade your work! In addition, please also name things in a way that makes sense! Here are some examples below, and you can find more in my example repository:

* You complete your assignment entirely in a Python notebook. You name it LabActivity01.ipynb and commit to github. You then link this file directly in Canvas.
* You complete your assignment using a notebook and a markdown file. You put them both in a folder and link the folder directly in Canvas to turn in your assignment. This will indicate to Yuyang and me that we should grade everything in the folder. 

Most of the time, you will likely only turn in a single notebook, but I would like to give you flexibility in cases where more writing might be appropriate. Note that .csv files, Word Documents, pdf files, etc can be committed to github. 

Note: It may seem like a lot of extra work to use github, but leveraging this tool, getting used to committing code, etc is something that you will almost certainly have to do as a data scientist. Every team I have worked on since 2011 has used github. Practicing now will set you up for success in the future. 

## Directly upload code and other files (Second Choice)

You can commit any files used to complete the assignemnts directly to Canvas. 


## Google Colab (Last Resort)

Per my note above, I strongly recommend that you setup your local Python environment (see the README for this repository for details) and leverage github. If for some reason this is not feasible, you can use Google Colab to turn in assignments but this is discouraged. In addition, please come to my office hours or Yuyang's office hours so we can help you get setup.
